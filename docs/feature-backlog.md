# feature-backlog.md — Long-list идей и приоритизация (заготовка для spec.md)

## Summary: «боль — возможность»

| Боль пользователя | Почему это важно | Возможность для продукта |
|---|---|---|
| Пользователь поздно замечает ухудшение настроения, усталость и тревожность. | Состояние накапливается постепенно и начинает влиять на сон, работу, отношения и мотивацию. | Дать быстрый ежедневный чек-ин, который помогает заметить динамику раньше. |
| Причины плохого состояния кажутся неочевидными. | Пользователь помнит отдельные события, но не видит повторяющиеся связи. | Показывать простые паттерны: «в дни с плохим сном тревожность выше». |
| Длинные дневники сложно вести регулярно. | В стрессе и усталости нет ресурса писать подробные тексты каждый день. | Микро-логирование за 30–60 секунд: шкалы, эмодзи, теги, короткий комментарий по желанию. |
| Пользователь не хочет получать банальные советы. | Советы без объяснения раздражают. | Обьяснимые рекомендации, привязанные к данным пользователя, сформулированные бережно. |
| Пользователь может не доверять ИИ-выводам. | Ошибочные/категоричные выводы вредят доверию в чувствительной теме. | Простые прозрачные правила, показ основания инсайта, без диагностических формулировок. |
| Пользователь переживает за приватность личных записей. | Записи о настроении/здоровье — очень личные данные. | Минимизация данных, локальное хранение в MVP, удаление записей, понятный дисклеймер. |
| Пользователь бросает трекер до накопления данных. | Без ранней пользы дневник — лишняя обязанность. | Ранний value moment: мини-инсайт после 3–5 записей, прогресс-индикатор. |

**Итоговая формулировка возможности:** быстрый и бережный mood diary, который не требует длинных записей, но показывает первые связи между состоянием и образом жизни уже через несколько дней. Не «лечение» и не «психолог вместо специалиста», а раннее самонаблюдение, обьяснимые паттерны и маленькие действия для восстановления.

## Long-list идей-функций по темам

**Быстрый daily check-in:** шкалы 1–5 (настроение/энергия/тревожность/стресс/сон), эмодзи, визуальный квадрант эмоций, super-fast режим, часы сна, главный фактор дня, быстрые теги, короткий комментарий по желанию, голосовой ввод (если успеваем), progressive disclosure, черновик записи.

**Персональные теги и контекст:** предустановленные теги (работа/дедлайн/конфликт/спорт/сон/отдых и т.д.), собственные теги, авто-подсказка из комментария, деление на негативные/нейтральные/позитивные.

**История и визуализация:** лента по дням, календарь настроения, **безопасная палитра (без красного как «плохо»)**, графики за 7 дней, сравнения сон–тревожность / стресс–энергия, карточки «лучший/сложный день».

**Инсайты и обьяснимая аналитика:** первый мини-инсайт после 3 записей, основной — после 5, недельный обзор, объяснение логики инсайта, уровень уверенности (низкий/средний/высокий), предупреждение «данных пока мало».

**Рекомендации и действия:** одна мягкая рекомендация в день, карточка «маленькое действие на завтра», персонализация на основе того, что уже помогало, рекомендация «обсудить со специалистом» при устойчиво плохом состоянии (без диагностики), возможность отключить рекомендации.

**Удержание и ритуал:** прогресс до первого инсайта, streak без чувства вины, **анти-геймификация** (можно отключить), нейтральные формулировки пропусков, бережные напоминания по выбору пользователя.

**Приватность, безопасность и доверие:** дисклеймер, объяснение каких данные сохраняются, локальное хранение для MVP, удаление отдельной записи и всех данных, без обязательной регистрации, запрет категоричных формулировок, режим «личный экран», PIN/Face ID (could-have), бережная кризисная логика при устойчиво низких оценках.

**Экспорт и сценарий с психологом:** экспорт недельной сводки, режим «что обсудить на терапии», скрытие личных комментариев из экспорта.

**Интеграции — future scope, не MVP:** Health Connect/Apple Health, wearable, календарь, экранное время — только после проверки ценности ручного дневника и с явного согласия пользователя.

**ИИ-функции — optional/later:** авто-теги, недельная ИИ-сводка, on-device AI как предпочтительный вариант, объяснение «почему я вижу этот инсайт». Жёсткое ограничение: без медицинских выводов, без оценки личности, без категоричных советов.

## Приоритизация (MoSCoW)

**Must have:**
- Check-in 15–20 сек с progressive disclosure
- 5 базовых шкал + предустановленные теги
- Первый инсайт после 3–5 записей: сон ↔ настроение
- Одна мягкая рекомендация на основе паттерна
- Прогресс до первого инсайта
- История последних записей
- Оценка полезности инсайта
- Компактный график за 7 дней
- Дисклеймер
- Безопасная палитра (без красного как «плохо»)
- Удаление записи

**Should have:**
- Короткий комментарий по желанию
- Недельный обзор
- Авто-теги из комментария, если комментарий включён
- Карточки «что совпадало с хорошими/плохими днями»
- Отключение геймификации
- Экспорт недельной сводки

**Could have:**
- Голосовой ввод
- Пользовательские теги
- Месячный календарь
- Персонализация рекомендаций
- PIN/Face ID
- ИИ-сводка недели без медицинских выводов
- Режим «для психолога»

**Won't have в MVP:**
- Диагностика и медицинские выводы
- Консультации специалистов внутри продукта
- Социальные функции
- Сложный ML
- Платные API
- Обязательная авторизация
- Интеграции с wearable/Health Connect/Apple Health/трекерами/календарём
